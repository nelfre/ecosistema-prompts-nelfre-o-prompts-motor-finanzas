## ⚡ Conexión y Uso en Arena.ai (Agent Mode)

Para utilizar esta suite en cualquier sesión de Arena.ai en Modo Agent, solo debes indicarme:

1. **Carga directa desde GitHub:**
   ```text
   Agente, clona mi repositorio de prompts: https://github.com/TU_USUARIO/TU_REPOSITORIO.git y activa el prompt de [Nombre del Canal o Blog]
   ```
2. **Generación por comandos:**
   * **Para YouTube:** `Generar guion para @GuerraDelMotor sobre [Tema]` o `Reempaquetar vídeo de @MotorAutopsiaEspaña`.
   * **Para el Blog:** `Generar artículo para el blog basado en este transcript/vídeo` o `Auditar y certificar esta entrada HTML`.

---

## 🛡️ Reglas Sagradas del Ecosistema

1. **Regla de Miniaturas:** 1 a 3 palabras exactas en el texto de la miniatura. Cero opciones secundarias ni paréntesis.
2. **Blindaje de Idioma:** Español de España nativo (`es-ES`), moneda en Euros (`€`), baremos de taller y normativas de DGT, ITV y EUR-Lex.
3. **Blog sin Huellas de IA:** 0 corchetes de citación `[x]`, 0 asteriscos markdown residuales `**`, atributos `alt` y `title` obligatorios, y tablas responsivas móviles.
